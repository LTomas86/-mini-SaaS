# Mini SaaS (skeleton)

This repository contains a minimal scaffold for a SaaS service with an Express API and React frontend.

## Structure

- `apps/api` – Express API skeleton
- `apps/web` – React frontend skeleton

## Development

```bash
npm install  # dependencies (placeholder)
npm run dev  # run API and web concurrently (placeholder)
```

## Testing

```bash
npm test
```
